# Напоминания «Возвращение к своему пути»

Отправляет только сервер через бота (приложение может быть закрыто). По умолчанию выключено: без явного включения пользователем личные данные на сервер не попадают.

## Что и когда отправляется
- Планировщик проходит раз в `REMINDERS_TICK_SEC` секунд (по умолчанию 60); отключить целиком — `REMINDERS_ENABLED=0`.
- Не больше одного сообщения в местный день на пользователя. План дня: итоги недели в выбранный день, иначе мягкое возвращение после перерыва, иначе ежедневное (частота: каждый день / через день / по будням / только итоги недели).
- Время и день считаются по часовому поясу пользователя; тихие часы (по умолчанию 22:00–08:00): сообщение сдвигается до их конца не более чем на 3 часа, иначе пропускается. Опоздавшее больше чем на 3 часа не отправляется.
- Ежедневное не отправляется, если пользователь уже заходил сегодня.
- Возвращение после перерыва: через выбранное число дней (2/3/5/7/14), не чаще раза в 7 дней, не больше 3 подряд. После 7 сообщений без захода в приложение — пауза до следующего захода.
- Тон: без вины и давления, без счёта пропущенных дней, без эмодзи; 72 текста в трёх стилях (тёплый, спокойный, по делу); тексты персонализируются целью, направлениями и ближайшими задачами, недавние не повторяются.
- Каждое сообщение содержит `/stop` и кнопку открытия приложения.

## Защита от дублей и сбоев
Журнал `reminder_log` с уникальным индексом (пользователь, вид, слот): повторные и параллельные проходы не создают дублей. 403 («бот заблокирован» / нельзя писать первым) — пометка «недоступен» без повторных попыток до нового `/start`; 429 — пауза на `retry_after`; прочие ошибки — до 3 попыток с интервалом 5 минут. В журнале хранится id текста, а не сам текст.

## API (авторизация `Authorization: tma <initData>`)
- `GET /api/reminders` — настройки, состояние чата (`chat.state`: unknown/ok/blocked), `paused`, `next_at`, допустимые значения.
- `PUT /api/reminders` — частичное изменение: `enabled`, `daily{on,time}`, `weekly{on,day 1..7,time}`, `freq`, `inactivity{on,days}`, `style`, `tz` (IANA), `quiet{from,to}` или `null`, `write_access` (после `requestWriteAccess`).
- `PUT /api/reminders/snapshot` — снимок для персонализации: `goal`(≤120), `dirs[≤8]{n≤40,p}`, `done`, `total`, `week{done,planned}`, `streak`, `next[≤3]{t≤80,d}`, `last_active`(мс). Принимается только при включённых напоминаниях.
- `POST /api/reminders/test` — пробное сообщение (3 в час): проверяет, что бот может написать пользователю.
- `DELETE /api/reminders` — удалить настройки, снимок и журнал.
- Команды бота: `/remind` (состояние), `/stop` (выключить и удалить данные для напоминаний).
- Админка: `GET /api/admin/reminders` — сводка без текстов и личных данных.
