# Mandala (Mandal-Art)

Telegram Mini App «Мандала целей»: мандала из 81 клетки, опыт и огоньки, дневник, реликвии и 3D-фигурки, аналитика, календарь сроков, магазин за Telegram Stars и напоминания «Возвращение к своему пути».

## Что в репозитории
- `mandal-art/` — клиент. Один файл приложения собирается командой `python3 build.py` (полная сборка) или `python3 build.py --public` (без картинок, права на которые не подтверждены) → `dist/`. Тесты — `tests/*.cjs` (Playwright, запускать по очереди).
- `mandala-shop/` — сервер магазина Stars и напоминаний (Node ≥ 22.13, без внешних зависимостей): `npm test`, `.env.example` с описанием настроек.
- `mandal-art/handoff/STATE-SHORT.md` и `mandal-art/STATE.md` — состояние работы и план; с них начинается любой новый чат.

## Чего здесь нет намеренно
Картинки персонажей франшиз (Warhammer 40K, One Piece, Scrooge/DuckTales) принадлежат правообладателям и лежат только в приватных файлах владельца; секреты (`.env`, токен бота) и данные сервера (`data/`) в репозиторий не попадают. Публичная сборка `--public` работает без них.

## Честные ограничения
Реальные платежи Stars, реальный Telegram и телефон (скорость, батарея) в песочнице проверить нельзя; тесты используют имитацию Bot API. 3D из картинок — это «объём из картинки» или «объём по трём видам», а не оригинальная 3D-модель; честные подписи режимов показаны в приложении.
